# minjunkim-labs

[MINJUN KIM](https://github.com/minjunkim-dev)의 개인 개발 프로젝트를 모아 둔 조직입니다.

모든 저장소는 [repo-baseline](https://github.com/minjunkim-labs/repo-baseline)의 같은 규칙으로 운영합니다. 구현은 AI 코딩 에이전트가 하고, 구현과 다른 컨텍스트의 리뷰, 필수 CI, 머지 큐를 거쳐 병합합니다.

## 프로젝트

| 저장소 | 무엇 |
| --- | --- |
| [Runstir](https://github.com/minjunkim-labs/mobile-runtime) | 앱 개발 환경 준비·실행 도구 (Swift 6.2, macOS CLI) |
| [smallnext](https://github.com/minjunkim-labs/smallnext) | 큰 목표를 지금 할 수 있는 다음 행동 하나로 바꾸는 플래너 (SwiftUI + Rust API) |
| [BGLike](https://github.com/minjunkim-labs/BGLike) | Godot 4 싱글플레이 전술 RPG 프로토타입 |

## 개발 방식

| 저장소 | 무엇 |
| --- | --- |
| [repo-baseline](https://github.com/minjunkim-labs/repo-baseline) | 모든 저장소가 따르는 규칙(POLICY), 템플릿, GitHub 설정 검사·적용 도구 |
| [repo-office](https://github.com/minjunkim-labs/repo-office) | 이슈 하나를 설계·구현·검사·리뷰 단계로 나눠 PR 직전까지 돌리는 에이전트 파이프라인 (실험) |
